# Site GEPAEd

Site institucional do **GEPAEd — Grupo de Estudo e Pesquisa em Argumentação na Educação**.

Página inicial (landing) do grupo: apresentação, carrossel de eventos, números, linhas de
pesquisa, últimas publicações (integradas à Biblioteca), frentes de atuação e conceitos-chave.

> **Versão inicial (v1):** vários conteúdos são placeholders marcados ("a validar"),
> aguardando textos institucionais, fotos de eventos e dados de contato do grupo.

## Estrutura
- `index.html` — landing
- `data.js` — dados das publicações (compartilhado com a Biblioteca)
- `img/` — identidade visual (logo)

## Módulos
- **Biblioteca** de produção científica: https://gabrielfortes-nees.github.io/biblioteca/

## Stack
Site estático no GitHub Pages. Evolução prevista para Quarto Website com as sub-páginas
(Quem somos, Pesquisa, Formação docente, Eventos, etc.).
